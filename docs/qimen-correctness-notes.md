# 奇門遁甲口徑修正記錄（v0.1.4）

> 日期：2026-08-28
> 狀態：已實施，附完整測試（`test/qimen.test.ts`，23 個用例）

本次修正解決了 v0.1.x 奇門模組中四類與傳統主流口徑不符的缺陷。
所有修正均以兩個獨立來源交叉驗證：張志春《神奇之門》（轉盤派經典）與
kentang2017/kinqimen（MIT，與本項目大六壬所引 kinliuren 同作者）。

## 1. 拆補法三元符頭（JuShuCalculator）

**修正前**：以日干支的旬首（十日）判元，且中元/下元映射顛倒。

**修正後**（傳統口徑）：
- 符頭 = 當前日所在五日組的首日（甲日或己日），非旬首
- 符頭地支四仲（子午卯酉）為上元：甲子、甲午、己卯、己酉
- 四孟（寅申巳亥）為中元：甲寅、甲申、己巳、己亥
- 四季（辰戌丑未）為下元：甲辰、甲戌、己丑、己未

## 2. 地盤三奇六儀布局（JiuGongCalculator）

**修正前**：按物理環序（1→8→3→4→9→2→7→6）布干，陽遁一局「己」落艮8。

**修正後**（傳統口徑）：按**宮位數字順序**飛布：
- 陽遁：從局數宮起順數（1→2→…→9→1）
- 陰遁：從局數宮起逆數
- 陽遁一局：戊坎1、己坤2、庚震3、辛巽4、壬中5（寄坤2）、癸乾6、丁兌7、丙艮8、乙離9

**根因**：`LUOSHU_ORDER = [1,8,3,4,9,2,7,6]` 被誤當作「洛書飛布順序」，
實為轉盤物理環序。此誤名導致了整個缺陷家族。

## 3. 轉盤式天盤/九星/八門（ZhuanPanCalculator）

**修正前**：
- 天盤按「序列重排」（從時干宮起重新順布戊己庚辛壬癸丁丙乙）
- 九星/八門按「時辰數環形旋轉」（與天盤邏輯脫節，值符星不隨時干）
- 九星環序錯誤（蓬芮相鄰）

**修正後**（剛體轉盤模型，《神奇之門》）：
- 天盤干、九星、八門是三個物理轉盤，**盤內環序恆定**：
  - 九星環序（物理順時針）：蓬任冲辅英芮柱心（禽寄芮）
  - 八門環序（物理順時針）：休生伤杜景死惊开
- 天盤與九星同轉：值符星攜旬首六儀轉到**時干（遁干）地盤落宮**
- 值使門落宮：從值符原始宮起，按干支**旬內序數**（甲為0）以宮位數字順數（陽）/逆數（陰），落中五寄坤二
- 中五宮之干寄坤二隨盤轉動

**註**：kinqimen 在陰遁時對門/星環序做鏡像處理，本項目採用主流轉盤口徑
（環序恆順時針，陰陽遁僅影響值符/值使落宮的推算方向），與問真等主流排盤一致。

## 4. 飛盤式天盤/九星/八門（SanQiLiuYi/JiuXing/BaMenCalculator）

**修正前**：飛布路徑使用物理環序；天盤起布恆為戊干。

**修正後**：按宮位數字飛布；值符隨時干（起布干 = 旬首儀）；
九星按原始宮數字序（蓬芮冲辅禽心柱任英）自值符星起飛布；
八門自值使門起飛布（跳過中五宮）。

## 驗證

- 單元級：60 甲子逐日三元表、各局地盤布局、環序循環同構不變量、干隨星轉不變量
- 端到端金樣本：2024-06-21 10:00（夏至當日，陰遁三局中元）全盤手工逐項推演並固化為測試
- 快照回歸：時盤/日盤 × 轉盤/飛盤 × 拆補/茅山 共 5 個配置組合

## 影響面

時盤/日盤拆補法與茅山法的局數、天盤、星、門佈局均可能與 v0.1.x 不同
（年盤/月盤不受影響）。用神分析建立在基礎排盤之上，隨之修正。
