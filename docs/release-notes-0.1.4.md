# v0.1.4

面向正确性与产品定位的重构版：修复了八字与奇门两类长期存在的排盘缺陷，确立「只输出确定性排盘量，解读交还 AI」的产品边界，新增多时区与大六壬时间起课。

## ⚠️ 升级须知（与 0.1.3 的不兼容变更）

1. **八字 · 二月出生者结果可能变化**：年柱此前在「立春至春节」窗口（每年 2 月上中旬约两周）按春节换年错排，连带月干、大运顺逆出错；现按立春精确时刻换年（分钟级边界经公开节气数据验证）。
2. **八字 · 晚子时（23:00–24:00）时柱变化**：改按次日干起五鼠遁（主流口径，与六爻/奇门/大六壬一致）。
3. **八字 · 提供经度（真太阳时）时四柱变化**：此前校正只作用于年/月柱而日/时柱仍按原始钟点（两套时间源混用），现四柱一律按校正后时刻排盘，输出附校正时刻。
4. **奇门 · 时盘/日盘结果与旧版不同**：修复四类口径缺陷（拆补法符头、地盘布局、转盘星门、飞盘飞布），修正原因与参照详见仓库 `docs/qimen-correctness-notes.md`。
5. **工具移除**：`qimen_zeri`（择日）——其输出为机器评分排行，评分属无权威口径的解读层；如需择时可逐时调用 `qimen_basic` 自行评估。
6. **输出内容收紧**：`bazi_basic` 输出四柱纳音/天干藏干十神/十二长生自坐/命宫/胎元/旬空/公农历；梅花不再附吉凶断语；奇门格局平列（不分吉格/凶格）；用神分析不再输出评分。五行强弱、格局吉凶、用神喜忌等解读由 AI 依据盘面完成。

## 新增能力

- **大六壬时间起课**：直接输入公历时间即可排盘，节气、月将、日/时干支自动推得（原显式参数保留为专家模式，节气名简繁均兼容）。
- **多时区**：所有时间类工具支持 `timezone` 参数（IANA 名，默认北京时间）；正确处理各国历史夏令时（含 1986–1991 中国夏令时，按标准时排盘）。
- **排盘完整性补齐**：八字纳音、藏干十神（全藏干逐个标注）、十二长生自坐、命宫（《三命通会》子平起法）、胎元（《渊海子平》月干进一支进三）；紫微五行局、命主、身主。

## 问题修复

- 八字年柱立春换年、晚子时口径、真太阳时四柱全量生效（上述三条的详细验证：历史人物权威记载用例——毛泽东/乾隆/蒋介石、立春分钟级边界用例、lunar-javascript oracle 回归）。
- 奇门遁甲四类口径缺陷（kinqimen 实跑交叉验证 + 手工金样本固化）。
- 修复 stdio 日志污染 JSON-RPC 流的问题（严格的 MCP 客户端此前可能解析失败）。

## 工程与质量

- 测试 117 → **218**：全部 16 个工具的输出契约测试、MCP 协议层集成测试、权威用例金样本。
