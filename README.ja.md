# Mingpan — AIエージェントのための東洋術数 確定性排盤エンジン

[简体中文（主文档）](README.md) | [English](README.en.md) | 日本語（このページ）

[MCP](https://modelcontextprotocol.io) のオープンソース計算エンジンとして、**四柱推命（八字）・紫微斗数・六爻・梅花易数・大六壬・奇門遁甲**の命盤を暦計算レベルの厳密さで排盤します。AIエージェントは得意な「解釈」に専念でき、幻覚に悩む「計算」はMingpanが担います。BaziWeiは公式ホスティングサービスも運営しています。

```text
https://mingpan.bzwai.com/mcp
```

Remote MCP / Streamable HTTP対応のAIクライアントに、このエンドポイントを追加するだけで利用できます。Node.jsのインストールやサーバーの自己運用は不要です。機能概要と接続手順は[Mingpanオープンソースプロジェクトサイト](https://mingpan.bzwai.com)で確認できます。公式サービスは[BaziWei](https://bzwai.com)が運営し、ソースコードと計算口径は本リポジトリで引き続き公開します。

ローカル開発や端末外にデータを出したくない場合は、stdioパッケージも利用できます：

```json
{ "mcpServers": { "mingpan": { "command": "npx", "args": ["-y", "mingpan"] } } }
```

## 解決する問題

LLMは干支・節気・暦の換算を確実には行えません——推論で誤った柱を「幻覚」として出力してしまいます。Mingpanは計算側だけを担う確定性エンジンです：

- **確定的な値のみ出力。** 四柱・納音・蔵干・十神・命宮・胎元・十二宮星曜・四化・卦構造など、出力はすべて検証可能な事実（古典の参照表に基づく）。五行スコアや吉凶ラベル、解釈的判断は意図的に含めません——それはAIの役割です。
- **正確性の規律。** 300件のテスト。立春境界の分レベル検証、史料・古典文献によるゴールデンケース、参照実装との相互検証、リモートMCP境界テスト、多言語プロジェクトサイト契約を含みます。
- **タイムゾーン・真太陽時対応。** IANAタイムゾーン入力（1986–91年の中国夏時間を含む歴史的DSTを処理）、経度による真太陽時補正は四柱すべてに一貫適用。CIでタイムゾーン横断の再現性を保証。
- **安全な公式サービス。** ステートレスなリモートサービスは出生入力や命盤結果を保存・キャッシュ・ログ記録せず、Host/Origin検証、リクエストサイズ上限、レート制限を適用します。

## 出力例（`bazi_basic`）

盤面は術語の正確性のため中国語（簡繁）で出力されます。構造：生年月日 → 納音付き四柱 → 空亡 → 命宮・胎元 → 天干十神 → 蔵干十神 → 十二長生。

```text
=== 命主資料 ===
性別：男
公曆：1992-04-12 07:30:00
農曆：壬申年三月初十辰時

=== 八字命盤 ===
年柱：壬申（剑锋金）  月柱：甲辰（覆灯火）  日柱：戊午（天上火）  時柱：丙辰（沙中土）
日柱旬空：子丑
命宮：己酉　胎元：乙未
天干十神：年干水=偏財　月干木=七殺　時干火=偏印
藏干十神（※本氣）：年申[庚食神※ 壬偏財 戊比肩]　月辰[戊比肩※ 乙正官 癸正財]　日午[丁正印※ 己劫財]　時辰[戊比肩※ 乙正官 癸正財]
十二長生（自坐）：年长生　月衰　日帝旺　時冠带
```

## 対応範囲

西暦1900–2100年 · 内部標準時は北京時間（UTC+8）· 解釈は意図的にAIに委ねます。
